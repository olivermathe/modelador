# Decisões

Histórico do que o usuário pediu e das escolhas feitas, para que mudanças futuras respeitem a
intenção original. Mais recentes no fim.

| # | Pedido / contexto | Decisão | Por quê |
|---|---|---|---|
| 1 | Ferramenta de modelagem própria em Electron, com biblioteca de componentes compartilhada pelo time | Electron + React + TS + React Flow + Zustand | Plano inicial do usuário; React Flow evita meses escrevendo canvas e conectores. |
| 2 | Separar o elemento da sua representação | Recurso existe uma vez; desenhos guardam ids e posições | Editar um recurso atualiza todos os desenhos. É o que faz a biblioteca funcionar. |
| 3 | Abrir uma pasta (repositório) com `application`, `tecnologies`, `relations`, `projects`, e mostrar a estrutura na lateral | Um arquivo JSON por entidade; árvore reflete a pasta real | Compartilhamento pelo Git em vez de backend; diffs legíveis por arquivo. |
| 4 | "Os recursos só devem ser persistidos quando eu clicar em salvar" | Tudo em memória, inclusive criar/renomear/excluir pastas; Salvar aplica o diff | Ver regras.md §1. |
| 5 | Excluir/renomear pastas de projeto | Renomear vira `move` aplicado no Salvar | Preserva arquivos ocultos e não regrava arquivos. |
| 6 | Várias tecnologias por recurso | Seletor com busca e criação (vírgula separa várias) | |
| 7 | Formas estilo draw.io e ordem de empilhamento | Formas vivem só no desenho; pilha `z` comum a formas e recursos | Formas são anotação visual, não arquitetura. |
| 8 | Campo de impacto (novo/alterado/excluído) em recursos e ligações | Campo opcional na **entidade** (vale para todos os desenhos) | Escolha feita sem pedido explícito; se o usuário quiser impacto por projeto, mover para o desenho. |
| 9 | Endpoints como recursos ligáveis ("recurso X chama endpoint Y") | Endpoint é recurso `type: endpoint` com `parentId`; aparece dentro do nó do dono com conectores próprios | |
| 10 | Indicador ao alinhar objetos | Guias magenta + encaixe a 6 px de tela | |
| 11 | Todos os tipos de ligação do ArchiMate | 11 tipos com notação oficial; ligações antigas ficam "Genérica" | "Genérica" evita reinterpretar ligações existentes. |
| 12 | Criar/editar Markdown com pré-visualização | `.md` em `projetos/`, modos Editar/Dividido/Visualizar | |
| 13 | Exportar desenho em JPEG | Imagem do desenho inteiro, 2×, fundo branco, sem conectores/seleção | |
| 14 | Paleta e Propriedades no painel direito | Abas; seleção abre Propriedades, clicar no fundo volta à Paleta | |
| 15 | Pastas em português: `projetos`, `aplicações`, `tecnologias`, `relações` | Nomes antigos continuam abrindo e são renomeados no Salvar; tolerância a NFD | Repositórios existentes não podem quebrar. |
| 16 | Remover cores por tipo de recurso | Tipos em cinza; cor só para impacto (também métodos HTTP e conectores) | Cor de tipo confundia com impacto. Ver regras.md §7. |
| 17 | Redimensionar recursos sem esconder o texto | Tamanho por desenho; texto quebra linha; altura mínima = conteúdo | Tamanho é aparência, não arquitetura. |
| 18 | Ao criar ou renomear um recurso, avisar se já existe e deixar escolher entre usar o existente ou criar novo | Verifica ao sair do campo Nome (ou Enter), comparando pelo slug do nome (o mesmo do arquivo), entre todos os tipos exceto endpoint. "Usar este" funde: o atual é trocado pelo existente em desenhos, relações e endpoints (repetidos somem) e é apagado. Opção extra "Voltar ao nome anterior" (Esc). | Recurso novo nasce com nome genérico ("Novo serviço"), então o momento de verificar é quando o nome é digitado. Slug igual = mesmo nome de arquivo, que hoje viraria `-2.json`. No renomear, "usar o existente" de um recurso salvo apaga o arquivo dele no Salvar; o aviso diz isso. |
| 19 | Verificar se o endpoint já existe no recurso ao criar ou renomear | "Adicionar" abre uma linha de método + caminho e só cria se a rota for nova; editar confirma ao sair do campo e volta ao valor anterior se repetir. Mesma rota = mesmo método e caminho ignorando maiúsculas, barra final e nome de parâmetro (`{id}` = `{pedidoId}`) | São o mesmo endpoint HTTP. Antes, "Adicionar" criava sempre `GET /`, que já podia existir. |
| 20 | Vários pontos para ligar, visíveis só com a ferramenta de relacionamento | Ferramenta Selecionar/Ligar (V/L/Esc) no canto do desenho; escolher um tipo em "Nova ligação" também ativa Ligar. 16 pontos por recurso (5 em cima/embaixo, 3 nas laterais), escondidos fora de Ligar. O ponto usado fica em `anchors` do desenho; arrastar a ponta de uma seta troca o ponto (no mesmo recurso) | Ponto de conexão é aparência, como a posição: fica no desenho. Sem ponto escolhido, a seta usa o centro do lado que encara a outra ponta, como antes. Com Ligar ativa, os recursos não se movem, para o arrasto sempre criar ligação. |
| 21 | Botão "Nova feature": modal com nome, número (Azure DevOps), pasta, ano e trimestre; cria `<ano>-<trimestre>-<número><nome>` com diagrama.json, processo.json e doc.md | Botão na barra superior e atalho em cada pasta de `projetos/`. Pasta `<ano>-<trimestre>-<número>-<nome>` (com hífen entre número e nome). `processo.json` é um desenho vazio, como `diagrama.json`; `doc.md` vem com um modelo (feature, período, seções). Tudo em memória até o Salvar | O pedido não tinha separador entre número e nome; o hífen foi escolha para legibilidade (confirmar com o usuário). O formato de `processo.json` não foi especificado. |
| 22 | Nomes na árvore ocupando o máximo de espaço; ações atrás de um botão "⋯" | Nome com `flex-1 truncate`; contagem de arquivos foi para a dica (title); botão ⋯ sobreposto ao fim da linha, só no hover; menu em portal | Os ícones de ação sempre visíveis no hover roubavam espaço do nome. |
| 23 | Redimensionar, recolher e expandir os painéis da esquerda e da direita | `ResizablePanel`: arrastar a borda interna (duplo clique volta ao padrão), botão de recolher; largura e estado no `localStorage` | É preferência de tela, não dado do repositório (regra 1 não se aplica). |
| 24 | Endpoints fora dos recursos: recurso apartado | Endpoint tem nó próprio no desenho; o dono (`parentId`) virou opcional e editável ("Pertence a"); a Paleta cria endpoint sem dono; "Adicionar" no dono coloca o endpoint logo abaixo dele no desenho aberto | Ligações para endpoint só aparecem com o nó do endpoint no desenho; o exemplo foi atualizado com os endpoints como nós. |
| 25 | Ao incluir recurso existente, carregar as ligações com quem já está no desenho; validar ligação duplicada | Carregar já existia (`withImpliedEdges`) e agora é testado. Ligação duplicada = mesmas pontas, mesma direção e mesmo tipo ArchiMate: em vez de criar outra, seleciona a existente (trazendo-a para o desenho se faltar) e mostra aviso. Trocar o tipo para um já existente é bloqueado | Tipos diferentes entre as mesmas pontas são ligações diferentes (ex.: Serve e Fluxo). |
| 26 | Recurso arrastado para cima ou para dentro de outro: ligações entre eles invisíveis, mas existindo | "Dentro" = o centro de um cai na caixa do outro (`model/nesting.ts`). As setas entre os dois não são desenhadas (nem na exportação); a relação continua em `relações/` e em `edges` do desenho. Ao soltar, o menor vai para a frente e um aviso conta as ligações ocultadas; o painel da relação diz que ela está oculta | Aninhamento já representa a relação, como no ArchiMate. Afastar os recursos traz as setas de volta, sem perda. |
| 27 | Paleta só com ícones (recursos, formas, ligações) e nome na dica; no desenho, ícone ao lado do nome, sem o selo do tipo | `components/Tooltip.tsx` (dica imediata, em portal); `RelTypeGrid` para as ligações na Paleta (o painel da relação mantém a lista com nomes); `ElementNode` sem selo de tipo, com o nome do tipo no `title` do ícone | Menos texto repetido; o ícone já distingue o tipo. |
| 28 | Renomear recurso com dois cliques no nome | Edição no próprio nó (Enter/clicar fora confirma, Esc cancela), com a mesma verificação de nome repetido do painel (`checkDuplicateName`). Em endpoints, dois cliques editam o caminho, com a verificação de rota repetida | Mesmo comportamento do painel, para não haver dois jeitos diferentes de renomear. |
| 29 | Ctrl+Z funcionando | Histórico de estados do conteúdo (recursos, relações, desenhos, documentos, pastas) no store, até 200 passos; mudanças com menos de 600 ms de intervalo viram um passo (arrasto, digitação). Ctrl+Z/⌘Z desfaz, ⇧⌘Z/Ctrl+Shift+Z/Ctrl+Y refaz; Ctrl+Z também no Mac. Com foco num campo de texto, desfaz a digitação. Botões na barra. Abrir/recarregar zera o histórico | Depois do Salvar o histórico continua, comparado com o disco novo, mas para numa mudança de pastas já gravada: desfazê-la poderia apagar arquivos que o app não conhece. |
| 30 | Duplicidade de endpoint pelas ligações, não pelo campo "Pertence a" | O campo `parentId` saiu: o dono é a ligação de Composição dono → endpoint ("Adicionar" a cria). Endpoint repetido = o recurso já está ligado a outro endpoint com a mesma rota; o app pergunta usar o existente (o novo é fundido nele) ou manter os dois. Repositórios com `parentId` são convertidos ao abrir. Nome do arquivo do endpoint mantém o prefixo do dono, agora vindo da ligação | Ligação é a fonte única de "de quem é". Manter o prefixo evita renomear arquivos. |
| 31 | "Já existe ligação entre os dois? Perguntar: usar a existente ou criar nova sem remover a outra" (idem para nome de recurso) | Qualquer ligação entre os dois, em qualquer direção e tipo, abre a pergunta (`ChoiceDialog`); antes o app bloqueava e só avisava. Trocar o tipo de uma ligação não pergunta mais. O aviso de nome repetido já seguia a regra | Decisão é do usuário. |
| 32 | Dois tipos de exclusão: do desenho e permanente | Delete/Backspace: só do desenho. Shift+Delete: permanente, com pergunta. Botão direito mostra os dois (recursos e ligações; ligações ganharam menu). Botões do painel: "Remover deste desenho" e "Excluir permanentemente" (com a mesma pergunta) | Querer esconder de um desenho sem apagar é o caso comum. |
| 33 | Novo tipo de recurso "Schema" | `type: "schema"`, ícone de chaves, na Paleta | Contrato de dados (payload, evento, tabela). |
| 34 | Segurar o botão do mouse, arrastar e selecionar vários | Arrastar no fundo do desenho desenha o retângulo de seleção (só entra o que fica inteiro dentro); Shift+clique soma/tira. Mover o desenho passou para botão do meio/direito, Espaço + arrastar ou dois dedos no trackpad; zoom com pinça ou ⌘ + roda. Ligações só entram na seleção se as duas pontas estão selecionadas. Arrastar um selecionado move todos (sem guias de alinhamento em grupo) | O React Flow marca as ligações que só encostam num recurso selecionado; isso faria um Shift+Delete apagar ligações com recursos de fora. |
| 35 | Travar qualquer objeto para não mover/selecionar sem querer | Recursos e formas têm `locked` no desenho. Travado: não move, não é selecionado (nem pelo retângulo), o mouse "atravessa" (dá para selecionar por cima de um contêiner travado); continua aceitando ligações com a ferramenta Ligar. Cadeado no item destrava; também pelo botão direito e pelo painel | Trava é aparência do desenho, como posição e tamanho. |
| 36 | Destravar pelo botão direito | Botão direito em cima de um item travado abre o menu dele (com "Destravar"). Como o item travado deixa o mouse passar, o clique chega ao fundo; `Canvas.tsx` (`lockedItemAt`) acha o travado embaixo do cursor. Tratado no contêiner do canvas porque o React Flow não repassa o botão direito do fundo quando ele também move o desenho | O clique esquerdo continua atravessando, para a seleção por cima de contêineres travados funcionar. |
| 37 | "A ligação de servidão está invertida" | A notação do Serve já seguia o ArchiMate (seta aberta em quem é servido). A causa era a troca automática de direção ao ligar a partir de um endpoint ("recurso chama endpoint"), que invertia o Serve (o endpoint é quem serve). A troca saiu: a direção é sempre a do arrasto. Novo "Inverter direção" no painel da relação e no botão direito da ligação | A semântica da direção depende do tipo; adivinhar errava. |
| 38 | Ligações devem aparecer até o fim mesmo com o recurso dentro de outro; só as dos sobrepostos ficam ocultas | As setas ficavam atrás de todos os recursos, então o recurso de fora cobria o trecho até o recurso de dentro. Agora a seta com ponta dentro de outro recurso é desenhada logo acima desse recurso de fora (`zFor` em `Canvas.tsx`, `containersOf` em `model/nesting.ts`); as demais continuam atrás dos recursos. "Chamado por" do endpoint não conta mais a ligação de dono | Acima só do contêiner, e não de tudo, para a seta não passar por cima de recursos que não têm nada a ver com ela. |
| 39 | "Nova feature" a partir de uma pasta modelo, com cópia exata | No modal: "Padrão" (3 arquivos) ou "Copiar de uma pasta modelo" (qualquer pasta do computador, lembrada por repositório). O processo principal lê a pasta (até 20 MB); desenhos e `.md` ficam editáveis, o resto (imagens, texto, pastas vazias) vira `pendingFiles` (base64) e é gravado como está no Salvar. Desenho do modelo não editado é gravado com o texto original | "Exatamente" = byte a byte; o app não reformata o que o usuário não mexeu. |
| 40 | Interpretar as pastas em português e em inglês (applications/aplicações, relations/relacionamentos…) | Cada pasta aceita vários nomes (`FOLDER_ALIASES`), sem diferenciar maiúsculas e acentos, e **não é mais renomeada** (substitui a migração do item 15). O app usa o nome canônico por dentro e mostra/grava no nome real | O repositório é do usuário (e do Git): renomear pastas sozinho mexe no histórico de todo mundo. |

## Pendências conhecidas

- Rótulos de setas que passam por trás de um recurso podem ficar escondidos (precisaria desenhar os
  rótulos acima dos nós com `EdgeLabelRenderer`).
- O app não valida se um tipo de ligação ArchiMate é permitido entre dois tipos de elemento.
- Sem colaboração em tempo real; o compartilhamento é pelo Git (botão Recarregar após `git pull`).
